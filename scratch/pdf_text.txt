Welcome
This guide helps you set up and use Isarva Restaurant POS in a simple way.
Please follow the steps one by one. Do not skip the early steps.
If something is not clear, ask your Isarva support person or your restaurant Admin.
Part A — Before you start
What you need
1. A computer, laptop, or tablet with internet.
2. Google Chrome or Microsoft Edge browser (recommended).
3. Your Company Code (given by Isarva).
4. Your Admin username and password / PIN (given by Isarva).
5. Your restaurant name, VAT / tax details, and branch address ready.
Important tips
1. Keep your password secret. Do not share it with everyone.
2. Always select the correct branch before taking orders.
3. If the screen shows Offline, you can still take some orders, but sync will happen when internet comes back.
4. Do not store customer card numbers in order notes.
Part B — First-time setup (do this only once per till)
Step 1 — Open the POS website
1. Open your browser.
2. Go to: https://app.restaurant-pos.isarva.in
3. Wait for the login / activate screen to open.
Step 2 — Activate this POS for your restaurant
This is the first and most important step.

1. On the screen, find Activate POS (or company code box).
2. Type your Company Code given by Isarva.

1. Check Caps Lock.
2. Tap Refresh on the login screen and try again.
3. Ask Isarva if your user is active.

1. Use the language switch (EN / AR) if you need Arabic.
2. You can change language anytime later.

1. Open Settings.
2. Open Company & Branches.
3. Check your company name, logo (if any), and VAT details.
4. Add each branch of your restaurant (name, address, phone).
5. Save the details.
6. On the top bar, select the correct branch for this till.
Note: Day close, tables, and stock work per branch. Always check the branch name before work.

1. Open Settings → Company Details (or ZATCA / tax section).
2. Enter correct company legal name, address, and VAT number.

4. Do not share ZATCA private keys on WhatsApp or email.

2. Create Categories, then Dishes.
3. Create Addons and attach them to dishes.
4. Set Tax, Units, Departments, Extra Charges as needed.
5. Sync other tills after save.

Step 2 — Add food items
1. Choose category.
2. Tap the dish.
3. Select quantity.

Step 3 — Understand the bill totals (Tax / VAT)
On the right ticket panel you will see:
1. Subtotal — food total before discount.
2. Discount (%) — money reduced after you pick a discount %.
3. Extra charges lines — if you switched on any charge (Example: Service charges, Parking).
4. VAT / tax lines — tax is calculated by the system from Tax settings and item tax. You normally do not type tax by hand on
the floor.
5. Total — final amount (includes VAT when tax is on).
Important: To change tax rates for the restaurant, Admin must go to Settings → Tax (and Tax Update / Menu details). On
the floor you only *see* tax on the bill.
Step 4 — How to use Discount on the floor
1. Open the table ticket (items already added).
2. Find the DISCOUNT row under the totals.
3. Tap a percent button: 0%, 7%, 10% (or other % your Admin set in Settings → Discount).
4. The active button becomes dark.
5. Check that Discount amount and Total updated.
6. Tap 0% if you want to remove discount.
Notes:
 Only use discount if your shop allows it.
 Discount % is for this table ticket.
 If no % buttons show, Admin must create discounts in Settings → Discount.
Step 5 — How to use Extra Charges on the floor
1. Extra charges must first be created in Settings → Extra Charges (and set Active).
2. On the table ticket, find EXTRA CHARGES.
3. Tap a charge pill to turn it ON (Example: “Service charges as per policy · SAR 150.00”).
4. Tap again to turn it OFF.
5. When ON, the charge line appears in the totals and Total increases.
6. Tax on that charge (if configured) is handled by the system.
Examples you may see: Service charges, Parking Charges, packing fee, and so on.

Step 8 — Change Table
Use when guests move to another table.
1. Open the current table ticket.
2. Tap Change Table.
3. Select the new empty / target table.
4. Confirm.
5. Old table should become free; order now shows on the new table.
6. Check floor map once.
Who can do this: users with Change Table permission (usually Food Server / Admin).
Step 9 — Merge Tables
Use when two tables want one combined bill.
1. Open the main / host table (the table that will keep the bill).
2. Tap Merge Tables.
3. Select the other table(s) to merge into this one.
4. Confirm merge.
5. Items from linked tables come onto the host bill.
6. Floor may show a Merged badge.
7. Settle once on the host table.
Tips:
 Merge carefully — confirm with guests first.
 After merge, pay on the host table.

Step 10 — Split (open Settle in split mode)
Split on the floor opens the Settle window ready for split payment (one bill, many payment methods or people).
1. Open table ticket.
2. Check Total is correct (discount / charges / VAT ok).
3. Tap Split.
4. Settle window opens (see Part E for Equal / Custom split and payment steps).
5. Add payments until Remaining is SAR 0.00.
6. Tap Confirm split (or confirm settle).
Step 11 — Settle (full payment)
1. Open table ticket.
2. Tap Settle (brown / main pay button).
3. Settle window opens: Settle — Table XX.
4. Amount due shows incl. VAT.
5. Follow Part E to take cash / card / voucher / split.
6. After success, table becomes free.
Step 12 — Add more items later
1. Open the same table again.
2. Add new items.
3. Tap KOT again for the new items only.
4. Update discount / extra charges if needed before final Settle.
Part E — Settle screen (payment, split, food voucher, gift card)
This is the window titled Settle — Table XX (same idea for Takeaway / Quick Serve / Barcode settle).
E1 — What you see on Settle
1. Amount due … incl. VAT — total to collect (tax already included when tax is on).
2. Equal / Custom tabs — for split bills.
3. Remaining bar — how much is still unpaid.
4. Quick buttons like Rest → Cash, Rest → mada, Rest → Visa / Mastercard, Rest → Apple Pay, Rest → STC Pay,
channel names if enabled.
5. Fill remaining / Half remaining — fill amount boxes fast.
6. Payment type dropdown + amount + Add.
7. Confirm split / confirm pay — enabled only when Remaining is 0.00.
E2 — Pay full bill with one method (simple)
1. Tap Settle from floor.
2. Tap Rest → Cash (or mada / Visa / etc.).
3. Or choose payment type, tap Fill remaining, then Add.
4. When Remaining is SAR 0.00, confirm.
5. Give receipt to guest.
